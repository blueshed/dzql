ZeroQL Nested Proxy API Examples

The new API syntax matches the documented patterns: api.operation.entity(params)

📖 Get Operations

api.get.organisations({ id: 1 })
api.get.venues({ id: 1 })

🔍 Lookup Operations

api.lookup.organisations({ p_filter: "..." })

🔎 Search Operations

Filters
api.search.venues({ filters: {} })

💾 Save Operations

api.save.organisations({ id?: N, name: "...", description: "..." })

🗑️ Delete Operations

api.delete.organisations({ id: N })

🔴 Real-time Events

All database changes trigger real-time events via WebSocket
