# Docs

**Guidance**: what eta is for and how to build on it. Where these and the code disagree, the code,
`CLAUDE.md` and the eta-app skill are right; say so and fix the doc.

- `stories.md` -- what eta is for, and how stories drive it.
- `bento/` -- where am I and what can I do: the directions (`README.md`), built in `src/bento.ts`,
  and two sets of sample designs (`design/`, `paintbrush/`).
- `first-app.md` -- a first app, step by step: chat, then leave, in the order you meet the words.
- `least-resistance.md` -- why eta suits an AI that builds apps, and what would make it the easy path.
- `eta-app-notes.md` -- the why behind the eta-app skill: the numbers, the reasons and the sketches
  (OAuth2, LDAP) that would weigh the skill down.

**The record**: what the kernel was asked for, kept because code comments cite it.

- `change-request.md` -- what the wedding asked of the kernel, eleven items, all done. A comment
  that says "item N" means these.
- `bento-request.md` -- the bento's rules built into the examples: kernel items K1-K3, then the
  wedding (W), chat (C) and the ticker (T), all done. A comment that says "K1" or "W3" means these.
