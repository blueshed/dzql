# To test on claude-web

The Claude Code sandbox environment comes with PostgreSQL 16 pre-installed but not running, and Bun can be installed via npm install -g bun (it was installed in this session three days ago). To use PostgreSQL, start it with pg_ctlcluster 16 main start. You'll likely encounter permission errors that require these fixes: chmod 600 /etc/ssl/private/ssl-cert-snakeoil.key, chown postgres:postgres /var/lib/postgresql/16/main /var/log/postgresql/postgresql-16-main.log /var/run/postgresql/, and chown postgres:postgres /etc/postgresql/16/main/pg_hba.conf. To simplify authentication for testing, edit /etc/postgresql/16/main/postgresql.conf to set ssl = off and edit /etc/postgresql/16/main/pg_hba.conf to change the IPv4 localhost line from scram-sha-256 to trust. After these changes, restart with pg_ctlcluster 16 main start and verify with pg_isready -h localhost -p 5432. You can then connect passwordlessly: psql -h localhost -U postgres -d postgres. After installing Bun with npm, it's available at /root/.bun/bin/bun and works with bun <script.js>. These tools are production-quality: PostgreSQL 16.10 and Bun v1.3.2, both fully functional for testing database-driven applications.
